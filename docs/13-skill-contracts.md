# 独立 Skills 与工作流交接契约

> 状态说明：本文保留对应开发阶段的计划或验证记录。当前已实现能力与发布缺口以 [Alpha 发布状态](29-release-readiness.md) 为准；首次使用见 [安装指南](28-install-and-first-video.md)。

状态：2026-10-17 架构基线。setup、voice、subtitles 已有本机 alpha 实现；其余为计划，不创建不可执行的占位 skill。本文更新早期将字幕并入视频的划分。字幕当前支持配音任务或音频加稿件，不代表完整视频包工作流已接入。

## 拆分原则

每个 skill 完成一个可独立请求、可检查产物的任务。用户可导入外部文件，不要求经过上一环节；结构化文件交接，不依赖聊天历史或某台机器的路径。缺少输入时只补齐该任务所需内容，不自动重做上游。

所有功能都应支持：读取标准制作包；把可接受的外部输入转成同一内部对象；保存来源和转换记录；返回可供下一步使用的文件。外部资料缺少来源、人物、风格等信息时标注未知，不编造。

## 技能边界

| Skill | 单独使用的输入 | 产物及下一步信息 | 不负责 |
| --- | --- | --- | --- |
| codoop-cast-setup | 指定功能或功能缺失报告 | 私有环境、资源及检查结果 | 创作或统一安装所有功能 |
| codoop-cast-research | 话题、自有资料或检索要求 | report.json + report.md；结论 ID、证据与来源、冲突及未知项 | 写口播或生成视频 |
| codoop-cast-script | 外部报告/资料，或 report.json | script.json + 易读稿；稳定段落 ID、展示文本、朗读文本、结论引用 | 写分镜或合成声音 |
| codoop-cast-storyboard | 外部稿件或 script.json | video-script.json + 审阅稿；口播引用、画面意图、屏幕文字、素材需求、动画锚点 | 固定最终秒数或生成所有素材 |
| codoop-cast-assets | 单个素材描述、自有素材，或分镜素材需求 | assets.json + 本地文件；素材 ID、来源/生成描述、摘要、尺寸、使用限制与状态 | 擅自改口播或重做无关素材 |
| codoop-cast-voice | 原始参考音频、已存声音和外部稿件 | 当前已有 WAV、任务清单和原稿/配音稿；后续补齐段落引用及实际配音文本映射 | 字幕时间或画面 |
| codoop-cast-subtitles | 外部音频 + 稿件，或配音任务 | alignment.json、subtitles.srt、checks.json；字词时间、文字映射、音频摘要与偏移 | 改稿补读或调整镜头内容 |
| codoop-cast-scenes | 完整分镜或外部画面说明，以及已备素材 | 可按时间定位的本地 HTML 场景包、场景清单、预览；元素 ID、动画锚点、画幅布局与资源依赖 | TTS、修改事实或导出最终有声视频 |
| codoop-cast-video | 标准制作包，或场景包 + 音频 + 字幕/时间映射 | 解析后的 timeline.json、预览和完整 MP4、渲染检查；输出配置和输入版本 | 自动研究、写稿、生图或替换已确认内容 |
| codoop-cast-produce | 话题或任意已有中间产物，以及目标成品 | 调用已实现 skills，保存项目索引和执行计划，交付制作包及视频 | 重复实现其他 skill 的业务逻辑 |

这里的 scenes 是画面制作，video 是时间绑定与合成导出；assets 可处理一张图，也可以复用本地素材，不强制调用生图。Agent 生图依宿主工具可用性，来源与联网状态必须记录，不能将其宣称为本地能力。

voice 已支持 --script-file 输入并保存原始稿件身份。一个段落可以拆成多个 TTS 分块，范围映射在实际字幕对齐后还原到原段落；不能把分块 ID 当成段落 ID。最新实现见[稿件到配音适配](22-script-audio-adapter.md)。

## 同一份内容中枢，多种实际产物

`video-script.json` 是可编辑的内容中枢，引用固定版本的 script、素材、场景和输出配置；口播正文只在 script 对象维护，不能复制出互相冲突的多份正文。单独交付时可以打包这些依赖，不要求有全局项目数据库。

分镜脚本记录表达意图和语音锚点，精确时间轴是根据选定音频和对齐结果编译出来的产物，两者分别版本化。用户修改内容脚本，不直接维护推导出的秒数。手动定时需要显式 override 字段，区分相对偏移和固定时刻，重算时报告失效覆盖值。

制作包内采用相对路径并检查不逃逸根目录；执行返回宿主可访问的绝对路径。所有对象有稳定 ID、schema_version 和 revision。引用格式包含 artifact_id、revision、对象 ID 与必要的内容摘要；不能仅靠文件名判断版本。

每步返回统一逻辑字段：执行状态、任务 ID、主产物清单、依赖引用、异常、待解决输入、可衔接能力。执行成功和可进入下一步分开：有未准备素材的分镜可以完成规划，但不能标记最终渲染就绪。不把下一步建议当成用户授权。

首版通过文件 schema 验证必填字段、引用和版本；外部文件由显式适配器导入。正式 schema 和 CLI 在各模块实现前锁定，这里不是当前 CLI 已支持的参数声明。

## 时间锚点

动画可绑定 scene 开始、口播段落开始/结束、特定词语出现及相对偏移。词语锚点需有段落 ID 和文本范围或 token ID，不能只写“出现隐私时”，因为同词可能重复。剪掉或修改锚点目标时标记待处理，不静默挂到别处。

先依据内容生成分镜及可伸缩场景，TTS 后用实际对齐结果绑定时间，再由 video 编译时间轴。字幕条目和镜头不一一对应。外部场景若已有可靠时间可以单独渲染；无锚点也无明确时长时要求补充，而不是凭字数伪造精准时间。

## 修改与最小重做

| 修改 | 需要更新 | 可复用 |
| --- | --- | --- |
| 一条调研结论 | 标记关联口播及分镜待复核，确认内容改动后更新下游 | 未受影响结论、段落和素材 |
| 一段口播 | 相关配音分块、对齐、锚点和下游偏移 | 无关声音与场景内容 |
| 一个图片需求 | 指定素材、引用它的场景和视频 | 口播、配音和字幕时间 |
| 场景样式或动画 | 该场景和视频 | 素材、音频与对齐 |
| 字幕样式或头像位置 | 布局检查与视频合成 | 调研、稿件、声音及字词时间 |
| 横竖屏或分辨率 | 场景重排、字幕/头像布局、视频 | 内容和音频；不适合裁切的图片可能需另制版本 |

重做创建新 revision，保留已确认版本。内容未变但时间整体移动时更新偏移，不重新生成声音。缓存依据实际依赖和参数摘要。局部复用不保证最终文件只编码局部；首版允许完整重新编码。

## 实施顺序

先锁定最小 script、video-script、assets、scene、alignment、timeline schema 与示例，并用现有 72 秒稿验证 ID 映射。随后做字幕对齐的本机选型和最小 HTML 场景渲染，串通稿件到 MP4。再交付 storyboard/scenes/assets 的独立 skill，最后补齐 research/script 和 produce 编排。技能规划不表示要求用户按照该开发顺序创作视频。

每个新 skill 随可运行实现发布，更新通用 setup 的必要功能注册；不提前在插件清单中宣称可用。
