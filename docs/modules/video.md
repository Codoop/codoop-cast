# 视频制作模块

实现进度：已进入标准脚本 → 本地 HTML → MP4 的样例验证，参见[首个动画视频样例](../17-html-video-validation.md)。当前是维护者原型，不代表 video/scenes/storyboard skills 或通用 video setup 已发布。

## 职责与输入输出

输入：稿件、配音、字幕或对齐产物、素材、画面风格、画幅、帧率和头像占位配置。

输出：分镜规划、统一时间轴、预览、MP4 视频和渲染清单。支持独立导入已有稿件、音频与字幕。

## 两阶段制作

规划阶段：根据稿件选画面类型，绑定语义段落或关键词，安排信息层级并确定素材需求。

定时阶段：读取真实音频及对齐结果，确定分镜边界、关键词动画及字幕显示。缺少字词对齐时可使用经过确认的段落边界，不伪造逐字精度。

## 基础模板

| 模板 | 内容与运动方式 |
| --- | --- |
| 问题开场 | 简短问题、背景素材缓慢推进 |
| 概念解释 | 简图与关键词逐步出现 |
| 素材讲解 | 图片或视频、局部标注与轻微镜头运动 |
| 对比说明 | 左右比较，随讲解高亮对应项目 |
| 结论收尾 | 一句话总结和简洁收尾 |

以上是可选表现手法，不是固定镜头清单。Agent 根据话题与标准分镜制作 HTML/CSS/SVG 场景；场景遵守明确的时间定位、就绪、布局检查和资源契约。本地逐帧渲染复用同一时间轴，不依赖实时录屏。具体内容和动画不固定在插件框架里。

每个画面强调一个主要信息点，避免整段稿子上屏。动效服务讲解，不按每条字幕机械切换画面。

## 头像、字幕和素材

- 右下角提供独立头像轨道，首版使用静态图片或占位动画；真实视频输入可后续扩展。
- 头像、字幕和内容布局避让，平台安全区通过输出配置设置。
- 优先用户自有素材；外部素材记录来源和使用条件。
- 缺少素材时使用信息卡或图解兜底，不自动塞入不相关画面。
- 字体与素材提前检查可读取、可使用；渲染阶段尽量只读取已准备的本地资源。

## 渲染与检查

先提供较低成本的预览，再按配置导出正式成片。渲染前检查素材、字幕边界、时间轴总长和模板字段；渲染后检查音视频流、画幅、时长及文件可播放性，并观看开头、结尾、场景切换和长字幕片段。

验收样片建议约一分钟，包含五类模板中的若干种、右下角头像和中文混排字幕。必须验证声音清楚、字幕可读、主题内容不被遮挡，替换一张素材后可复用已有配音与对齐结果。

首版允许最终视频完整重渲染；后续再根据性能瓶颈引入场景级缓存或增量渲染。
