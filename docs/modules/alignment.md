# 字幕与对齐模块

当前状态：计划阶段，详细选型、实施顺序及验收见[字幕与对齐实施计划](../12-alignment-implementation-plan.md)。优先验证 Qwen3-ForcedAligner，WhisperX 作为备选；尚未锁定或安装默认引擎。

## 职责与输入输出

输入：最终配音或分段音频、对应朗读文本、展示文本映射、字幕排版配置。

输出：字词时间戳、段落边界、字幕条目、SRT 文件、对齐异常。后续可增加 ASS。独立运行支持用户导入自己的音频和对应稿件。

## 工作流程

1. 检查音频与稿件是否匹配；明显漏读或重复应返回配音环节处理。
2. 根据对齐模型需要重采样输入副本，保留原始音频作为时间基准。
3. 将已知朗读文本与实际语音做强制对齐。
4. 将朗读形式映射回展示文字，保留数字、标点及缩写的可读形式。
5. 按语义、显示长度、停留时长和画幅生成字幕。
6. 加入音频段偏移，输出全片字幕与校验结果。

## 时间与显示约束

- 字幕条目末尾不显示标点，句内标点保留；这是展示规则，不修改原稿、朗读文本或对齐时间。百分号等有语义的符号保留。

- 不按字数均分时长，不将未经核对的 ASR 文本直接替代稿件。
- 时间戳必须有序且在音频范围内；首版普通口播字幕不重叠。
- 不允许负时长、零长度条目或一闪而过的大段文字。
- 低可信结果如引擎不提供置信度，用越界、异常间隔、缺失映射等规则标记，不编造模型分数。
- 字幕按实际字体和画幅检查换行；不能只用固定字数判断是否溢出。
- 对齐成功不代表发音正确，仍需保留配音核查和试听入口。

验收：覆盖中文、数字、英文混排、停顿和分段拼接；导出的 SRT 可加载；段首段尾抽查同步；音频修改后旧结果明确失效。
