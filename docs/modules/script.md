# 口播稿撰写模块

## 职责与输入输出

输入：用户报告或调研产物、目标受众、目标时长、语言、表达风格。

输出：可阅读稿件、带稳定段落 ID 的结构化稿件、展示文本与朗读文本、可用时保留来源关联。用户自行导入的报告如果缺少证据，应明确其事实尚未核验。

## 工作流程

1. 提炼报告核心结论与必要限制。
2. 组织开场、解释、例子和收尾。
3. 依据时长目标控制篇幅，初始时长只是估算。
4. 使用适合中文口播的规则润色，可参考 Humanizer-zh。
5. 对照报告复核事实、数字、因果和不确定性。
6. 按语义划分段落，生成朗读规范化文本。

## 写作规则

- 句子简短，一句话尽量说明一个意思。
- 少堆术语，必要时用例子解释。
- 开场表达具体问题或价值，不夸张承诺。
- 不虚构亲身经历、人物引语和来源。
- 润色不能将“可能”改成“必然”，不能改变数字。
- 多音字、日期、单位及英文缩写允许显式设置读法。

模型生成的画面建议可交给视频模块参考，但稿件模块不分配最终分镜时长。

## 编辑与验收

允许用户在配音前确认稿件。修改段落保留 ID 并增加版本；拆分或合并段落产生新 ID 并记录关系。

验收：可独立导入报告写稿；重要结论不偏离原资料；可导出纯文本；朗读文本与展示文本可对应。实际配音超出目标时长时优先修改稿件或适度调整语速，然后重新对齐，不强行切断音频。
