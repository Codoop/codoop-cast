# codoop-cast v0.1.0-alpha.3: Clearer Skill Names

[English](v0.1.0-alpha.3.md) | [简体中文](../../zh-cn/releases/v0.1.0-alpha.3.md)

This alpha makes Codoop Cast skills easier to distinguish from other Codoop plugins in skill lists.

## Changes

- All 10 skill display names now use the `Codoop Cast: …` prefix: Setup, Research, Script, Voice, Subtitles, Storyboard, Assets, Scenes, Video, and Produce.
- Existing `$codoop-*` invocation names, default prompts, and runtime behavior are unchanged.

## Upgrading

Update the complete plugin through your host, or rerun the fallback installer from the updated source.

This release changes UI metadata only; existing configuration, voices, and content projects require no migration. The [alpha validation scope and limitations](../29-release-readiness.md) still apply.

[Compare changes](https://github.com/Codoop/codoop-cast/compare/v0.1.0-alpha.2...v0.1.0-alpha.3).
