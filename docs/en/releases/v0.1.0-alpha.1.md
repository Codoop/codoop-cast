# codoop-cast v0.1.0-alpha.1

[English](v0.1.0-alpha.1.md) | [简体中文](../../zh-cn/releases/v0.1.0-alpha.1.md)

Initial public-source alpha for users willing to report installation/content-quality issues.

- Ten independent skills for research, narration, GPT-SoVITS reference speech, real-audio captions, storyboards/HTML and MP4.
- Project versions, sequential agent batches, automatic assets, targeted regeneration and recovery.
- English instructions with configurable artifact language; private on-demand dependencies and shared models/tools.
- Apache-2.0 project code; separate model/dependency/font/media terms.

Validated scope: maintainer Windows/NVIDIA Chinese workflow and isolated fallback install. Native hosts, clean-machine end-to-end work, AMD/macOS, English listening and fresh-topic batch quality remain unverified. No voice training, lip sync or automatic posting.

Start with [installation/first video](../28-install-and-first-video.md). Report host/version, OS/GPU, steps and redacted errors; do not publish references/profiles/credentials/private task directories.

This release-note draft does not itself create a GitHub Release or upload anything remotely.
