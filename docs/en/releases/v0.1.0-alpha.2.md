# codoop-cast v0.1.0-alpha.2: Configurable Video Production

[English](v0.1.0-alpha.2.md) | [简体中文](../../zh-cn/releases/v0.1.0-alpha.2.md)

This alpha improves production configuration, skill naming, and documentation for the local-first topic-to-video workflow.

## Highlights

- **Configured video production:** Read language, orientation, resolution, frame rate, subtitle style, and avatar placement from shared or project configuration. Explicit task requests override saved defaults. Video preferences are merged by field and pinned in `output-profile.json` for consistent planning and rendering.
- **Predictable visual revisions:** Effective format changes require a new visual plan. Preserve narration and source content while rebuilding affected visuals and exports. Workflow checkpoints reject profiles that conflict with explicitly configured production settings.
- **Consistent skill names:** All 10 public skills now use `codoop-*`, including `codoop-setup`, `codoop-research`, `codoop-voice`, and `codoop-produce`, following codoop-flow's naming style.
- **Bilingual project documentation:** English and Simplified Chinese editions live in `docs/en/` and `docs/zh-cn/`, with language navigation. Skill instructions and references remain English.

## Upgrading

Update the complete plugin through your host, or rerun the fallback installer from the updated source. Do not copy individual `SKILL.md` files without the shared runtime.

The fallback installer retires only legacy discovery links owned by this plugin. Unrelated plugins, existing voices, tasks, and content projects are preserved. Existing workflow records route to the new skill names without rewriting their saved plans.

Language-only configuration remains valid. To add video defaults, tell your agent the desired format, such as “Use Chinese, portrait 1080×1920 at 30 fps by default.” See the [production configuration guide](../31-production-configuration.md) for the schema and override behavior.

## Validation

- 185 automated runtime and production-contract tests passed.
- All 10 skills passed format validation.
- Documentation pairing and 556 local links passed validation.
- The installed CLI was checked by saving landscape 1280×720 settings and creating a matching output profile, including the configured frame rate, subtitle size, and avatar visibility. This configuration check did not render a new video or synthesize new speech.

## Alpha limitations

The validated media workflow remains the maintainer's Windows + NVIDIA Chinese production setup. Native agent installation, clean-machine end-to-end installation, Windows AMD, macOS, English voice quality, and broader fresh-topic batch quality still require separate validation.

Image generation depends on tools available in the host agent. Voice training, lip-sync avatars, and automatic social-media posting are not included. Project code is Apache-2.0; third-party models, dependencies, fonts, and media retain their own terms.
