# 工作流程与数据约定

本文件描述概念契约，具体函数签名和字段在各模块实施时细化。统一使用 `schema_version`，模块通过结构化产物交接，不解析聊天记录作为正式输入。

Skill 职责、独立输入、稳定 ID 与版本引用、内容脚本和精确时间轴的区别，以[独立 Skills 与工作流交接契约](13-skill-contracts.md)为最新架构基线。具体话题决定画面与动画，HTML 是首选呈现方向，不固定整套镜头内容。

## 独立与串联

完整流程：话题 → 资料与证据 → 报告 → 口播稿 → 分镜规划 → 分段配音 → 配音检查 → 对齐 → 分镜定时 → 渲染。

允许任意合理入口：用户导入报告直接写稿；导入稿件直接配音；导入音频和对应稿件直接对齐；导入完整制作包直接渲染。

分镜规划不依赖音频时长；分镜定时依赖最终音频及其对齐结果。第一版各环节顺序执行即可。

## 项目产物

固定目录、文件名、版本及当前版本选择遵循[项目目录规范](20-project-layout.md)。根标记为 cast-project.json，各环节按 research/v001、script/v001、storyboard/v001、assets/v001、voice/v001、subtitles/v001、scenes/v001、exports/v001 保存。按需创建，不能再使用旧草案中的 project.json、audio/、alignment/、renders/ 或 plan.json 作为新项目默认命名。

跨项目环境、模型及声音档案留在共享数据根。项目内保存内容产物及已使用版本；最终导出包含完整 production/ 制作包。

## 关键数据对象

| 对象 | 必要信息 |
| --- | --- |
| Project | ID、数据结构版本、语言、画幅、帧率、当前有效产物版本 |
| Source | ID、URL 或文件路径、标题、资料日期、抓取时间、正文快照 |
| Claim | 结论、关联来源 ID、证据片段、不确定性或冲突说明 |
| ScriptSegment | 稳定 ID、展示文本、朗读文本、来源结论 ID |
| VoiceProfile | ID、参考音频及文本、引擎、模型版本、默认参数 |
| AudioSegment | 稿件段落 ID、音频路径、样本数、采样率、生成参数、核查状态 |
| Alignment | 段落 ID、字词起止时间、字幕条目、文本映射及异常状态 |
| Scene | ID、关联段落或字词、模板、素材、画面要点 |
| Timeline | 最终音轨、字幕、分镜与头像轨道、制作参数及版本 |
| Task | 输入产物版本、阶段状态、错误、输出清单、缓存标识 |

展示文本如“2026 年”，朗读文本可规范为适合 TTS 的形式。必须保留两者映射，确保字幕显示原意且能对齐到实际发音。

## 统一时间轴

- 最终旁白以 WAV/PCM 作为编辑阶段音频依据，导出时再编码。
- 音频段时长以实际样本数和采样率计算，包含拼接时加入的停顿。
- 对齐结果先记录段内时间，再加该段在最终音轨的偏移量。
- 时间轴保存绝对起止时间，渲染时从绝对边界换算帧号，避免逐段四舍五入累积漂移。
- 字幕可以一段多条；画面可以覆盖多个字幕条目。
- 最后一帧应覆盖旁白结尾；编码和拼接后的最终结果需要抽查同步。
- 修改速度、音频裁切或停顿后，对齐及依赖它的时间轴均须失效重算。

## 版本、缓存与恢复

任务状态：`pending → running → succeeded / failed / cancelled`。输入变化后对应结果标记为 `stale`，重跑创建新任务记录。进程异常退出后，将遗留的运行任务标记为中断，保留错误与已完成产物。

缓存标识包含：输入内容摘要、模型及规则版本、引擎版本、有效参数、声音档案版本；渲染缓存还包含模板、字体、素材内容摘要与输出配置。不要仅按文件名判断是否可复用。

| 修改内容 | 重做范围 |
| --- | --- |
| 某段稿件 | 对应配音、对齐；复核分镜；重算后续偏移及视频 |
| 声音配置 | 受影响配音、对齐、时间轴与视频 |
| 某张素材 | 对应画面及视频，配音与字幕可复用 |
| 字幕样式 | 字幕显示与视频，不重新生成声音 |
| 报告事实 | 标记下游稿件待复核，确认后再使相应下游结果失效 |

单段重做不等于最终视频只编码该段；首版允许复用中间产物后完整重渲染视频。

每步先写临时产物，验证完成后再更新当前有效版本。取消任务不删除之前成功版本；并发任务使用独立 ID 与输出目录。
