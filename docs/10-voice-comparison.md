# 音色改善：同稿对比记录

状态：已完成第一轮本机推理对比，尚未由用户选择偏好，不修改默认模型或现有声音档案。无需训练或新增用户操作参数。

## 对比方法

同一份短稿、语速 1.0、随机种子 42，其他采样参数相同。A/B 比较参考片段，A/C/D 比较匹配权重的不同预训练模型组合。模型比较不只是替换一个声学权重，Pro 系列还使用其配套语义权重和说话人编码器。

| 样本 | 模型 | 参考片段 | 生成时长 |
| --- | --- | --- | --- |
| A | v2 | 原自动选择的约 4.63 秒 | 17.70 秒 |
| B | v2 | 同一录音中另一段约 7.59 秒 | 20.38 秒 |
| C | v2Pro | 与 A 相同 | 16.34 秒 |
| D | v2ProPlus | 与 A 相同 | 16.34 秒 |

A/C/D 的主参考片段保持一致；B 有意测试更长且不同位置的语句，不据此认定参考越长越好。所有文件检查为非空、有效音频，四个输出的内容摘要不同。

试听副本做基础 RMS 音量匹配并限制峰值，不改变音高和速度；保留未处理原始输出。RMS 匹配不是感知响度或音色相似度评分。

用户应比较音色、说话习惯、读音和自然度；代码成功、模型更大或模型名称不能证明更像目标人物。最终声音相似度仍需用户试听。

## 实现与资源

维护者脚本 `scripts/compare_voice.py` 使用私有语音环境，独立输出对比结果，不修改已保存的声音档案或正式配音配置。可选推理权重的固定来源、大小与 SHA-256 记录在 `runtime/codoop-cast/resources-voice-comparison.json`，不加入普通 setup 的强制下载清单。

v2Pro/v2ProPlus 已在 RTX 3070 Ti 8GB 加载并完成推理。适配器校验上游实际识别的模型版本，避免表面加载新文件却仍按原模型运行。未修改上游源码；目前仅供对比实验，尚未通过正式 CLI 暴露模型选择。

16 项自动化测试通过；本次实际 A/B/C/D 生成也验证了适配器默认 v2 及两个 Pro 分支。尚未完成其他显卡、Agent 原生安装或跨机器复现验证。
