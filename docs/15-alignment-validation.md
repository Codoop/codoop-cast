## 实测环境与选型

Windows 10 / RTX 3070 Ti 8GB，独立 envs/alignment，Python 3.10.11，torch/torchaudio 2.5.1+cu124，Transformers 5.13.0，accelerate 1.12.0，原生 Transformers AutoModelForTokenClassification。使用 CUDA float16 + SDPA，没有安装 FlashAttention、vLLM 或 qwen-asr 演示服务依赖，没有修改声音环境。

采用官方原生 checkpoint Qwen/Qwen3-ForcedAligner-0.6B-hf，revision `c07281df297b9905d24a508279258cccf987a064`，权重 SHA-256 `00568245ceca5af1991d28562a75fe1ddc9bfeb041c27fda66947ea05c47fb86`。资源与校验值保存在 resources-alignment-experiment.json，运行前再次校验本地文件。模型卡标注 Apache-2.0；本项目代码许可证仍未选定，不据此推导所有依赖许可。

使用官方原生路径是为减少无关界面及多语言分词依赖，不是对旧 qwen-asr 包 Windows 兼容性的否定；旧包只做了解析检查，没有完成实际安装验证。

## 72 秒样例

输入为已验收任务 `127329545b5b4af4a0ca205b4f47ae91` 的当前导出与 4 个选定音频块。按实际原始采样偏移累加；只对副本重采样为 16k。最终音频仍是原始 32k、2,304,000 样本、72 秒。

初次原始输出 279 个正文单元，三个零时长字。首次实验拒绝导出；后续仅在同段文字紧邻、时间差不超过 160 毫秒且邻居有正时长时组合单元，保留 raw-alignment.json、raw-units.json 与精度警告。组合后的时间只属于多字单元，不声称这些字有独立精确时间。不增加虚构时长，不跨明显停顿合并。上游解码本身包含单调修复，原始分类预测 ID 也保留。

最终 alignment-03：276 个对齐单元、26 条字幕，包含全部 279 个正文字符（不含标点）。无倒序、越界、非法重叠或零时长单元，SRT 毫秒取整检查通过，三个组合精度警告保留，仍为 needs_review。使用 jieba 辅助词边界及短条合并，断句尚需人工观看。

实测模型加载约 1.52 秒，四段 forward+decode 合计约 0.70 秒；记录总过程约 2.81 秒，含模型加载及字幕分组，不含解释器启动、库导入、权重校验与下载。峰值 CUDA 已分配 2,074,262,016 字节，reserved 2,359,296,000 字节。速度仅代表本机本例。

已生成字幕核对预览 subtitle-preview.mp4：纯色背景、原始旁白、烧录字幕，720×1280、30fps。它不是主题动画或可投稿成片。提取第 8 秒画面确认中文字体可显示且字幕在画面内；尚未完成用户对开头/中间/结尾的同步验收，不能声称达到 200 毫秒目标。

真实 alignment 与音频已接入输出目录内的制作包副本，更新 revision、引用和摘要，通过跨文件验证；HTML 场景未实现，timeline 保持 blocked。仓库公开示例仍保持无个人音频的待生成状态。

## 混排样例与未通过项

用户已观看 72 秒核对预览并确认字幕和时间轴正常，另要求每条字幕末尾不带标点。默认显示规则已调整为去除条目尾部标点、保留句内标点与有语义的符号，不重跑配音或对齐。此反馈只验收该纯中文样例，混排问题仍待解决。

另生成任务 `cf22280eea8941e3a1f57fe884d5707e`，35.22 秒，包含日期、99.5 元、CPU/GPU、1080P、SRT。原稿 token 文本覆盖 114 个正文字符，但 1080P 时间为零，无法在保守邻近规则下组合，SRT 未导出；另有一条约 400 毫秒的短字幕。

检查 TTS 本地日志发现实际前端文本：日期读作“二零二六年十月十七日”，99.5 读作“九十九点五”，CPU/GPU/SRT 按字母拆开，1080P 使用“幺零八零P”。直接将显示文本交给对齐器并不能保证可靠时间戳。当前 voice 中保存的配音稿是送入 TTS 前的文本，并未完整保存内部规范化输出；这是下一步要补齐的真实交接缺口。

下一步从配音适配器记录实际规范化文本，建立展示文本到朗读文本的分组映射，再重测混排。不能通过猜测数字读法、跳过单词或放宽错误检查宣布通过。外部音频、长音频窗口、漏读检测及横竖屏真实字幕布局尚未验证。

维护者脚本 scripts/align_experiment.py 接受本地任务目录、模型目录与新输出目录，离线本地路径加载，不开启 HTTP 服务。实验依赖清单和 Windows 冻结约束不进入普通 setup；尚未提供通用用户安装入口。
