> 状态说明：本文保留对应开发阶段的计划或验证记录。当前已实现能力与发布缺口以 [Alpha 发布状态](29-release-readiness.md) 为准；首次使用见 [安装指南](28-install-and-first-video.md)。

## 目标

对外产品为开源 Agent 插件，用户安装后通过 skills 使用本地能力。插件分发、首次初始化和使用体验遵循[插件体验设计](05-plugin-experience.md)，属于各模块交付要求。

帮助用户将一个知识话题制作成可发布到社交媒体的口播视频，减少重复查资料、配音和剪辑的操作。用户可以只调研、只写稿、只配音或只制作视频。

本文件是讨论基线，不代表已完成技术验证。以下开发顺序为建议，可按需要调整。

## 第一版范围

- 声音档案：导入参考音频和文本，复用指定声音配置。
- 话题调研：支持联网资料及用户提供的资料，输出小白可读报告及来源。
- 口播稿：按受众、风格和目标时长生成稿件，支持中文口语化润色。
- 配音：调用本地 TTS，分段生成，允许试听和局部重做。
- 字幕：按真实音频对齐已确认稿件，导出 SRT。
- 视频：使用动态模板、用户素材和右下角头像占位合成 MP4。
- 任务：保存中间产物、失败状态和制作配置。

后续扩展：批量话题、外部素材检索、多画幅模板、ASS 样式字幕、真实头像视频。

声音训练、微调和训练数据管理不属于本插件产品范围，不列为后续任务。首版另不纳入自动投稿、数字人口型生成和完整剪辑器。

## 模块边界

调研模块不调用 TTS；写稿模块不负责配音；配音模块不排字幕；对齐模块不修改事实和文案；视频模块不补写研究结论。编排层负责串联及保存状态。

分镜属于视频模块，可读取稿件提前规划，但实际时长在音频生成后确定。

## 里程碑

| 阶段 | 工作 | 完成标准 |
| --- | --- | --- |
| M0 环境与选型验证 | 确认宿主、硬件、画幅；试听候选 TTS；验证渲染器 | 一段中文稿完成本地配音和简短视频渲染，记录速度、显存和问题 |
| M1 声音模块 | 声音档案、分段生成、试听、重做 | 同一档案可重复调用；重做一段不会丢失其他音频 |
| M2 对齐模块 | 已知文本强制对齐、字幕断句、导出 | 中文、数字和英文混排样例可播放核对；异常有明确提示 |
| M3 视频模块 | 分镜、基础模板、头像占位、渲染 | 一条约一分钟样片音画字幕同步，局部改图后可重渲染 |
| M4 写稿模块 | 报告提炼、口播结构、润色、事实回查 | 生成可独立编辑的稿件，重要结论能回到报告来源 |
| M5 调研模块 | 检索、正文提取、证据整理、报告生成 | 报告通俗易懂，来源可查；资料不足或冲突时明确说明 |
| M6 编排与批量 | 单独入口、串联入口、缓存、恢复、任务列表 | 多任务不会覆盖产物；中断后可从有效阶段继续 |

每个模块先交付独立调用能力、输入输出样例和使用说明，再接入完整流程。模块通过 Python 函数、结构化文件及必要的本地进程交互，不设计 HTTP 接口。

## 验收方式

使用少量真实中文样例进行端到端验证：概念解释、数字与英文混排、来源冲突、配音重做、素材缺失、任务中断。模型自然度、画面质量和同步效果需要人工试听及观看，不能只凭命令成功判断。

## 待确定事项

1. 插件宿主已确定为 Agent 插件，优先适配 Codex、Claude Code 和 Cursor；原生安装仍需分别验收。
2. 运行环境已检查：Windows 10、RTX 3070 Ti 8GB、约 32GB 内存；安装前复查可用磁盘与依赖兼容性。
3. 主要平台、画幅、单条时长和预期批量规模。
4. 是否用于商业运营；据此核对模型、依赖及素材许可。
5. 首批参考声音、测试稿、视觉风格与自有素材。
6. 是否允许联网检索；是否需要完全离线资料模式。
