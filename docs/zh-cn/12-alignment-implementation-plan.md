## 用户体验与范围

独立 skill 暂定 `codoop-subtitles`。用户可以说“给刚才的配音生成字幕”，或提供本地音频和对应稿件。插件自动准备依赖、对齐、断句并导出 SRT，不要求用户选择模型、输入时间码或手动分段。

第一版聚焦已知稿件的单人中文口播，包含数字和少量英文。音频没有稿件时说明缺少什么，不把任意音频转写扩展为本阶段必交能力。不开 HTTP 服务，不训练，不加入说话人分离、翻译、卡拉 OK 逐字高亮或 ASS 样式编辑。

## 技术候选与决策

| 候选 | 与任务的关系 | 验证重点 | 当前决定 |
| --- | --- | --- | --- |
| Qwen3-ForcedAligner-0.6B | 官方独立 align 接口，输入音频与文本，返回字词时间戳 | Windows 安装、8GB 显存、注意力实现、中文数字英文映射 | 优先做最小本机验证，未锁定 |
| WhisperX + 中文对齐模型 | 已有中文对齐适配，可对接已知文本区间 | 中文词表覆盖、数字英文、无时间戳项处理及依赖体积 | 第一备选 |
| FunASR 时间戳方案 | 工具箱有时间戳相关能力，但具体任务取决于模型和入口 | 必须确认选定模型能对齐已知稿件，而非只有转写时间戳 | 暂不优先集成 |

官方 Qwen 仓库说明其对齐器支持中文等 11 种语言及最长 5 分钟输入；这不是插件要求用户自行裁切的理由。优先利用本插件的真实配音分段；外部较长音频需要自动窗口与文本定位方案，不能把整篇稿件复制给每个窗口。若此路径未通过验证，应明确限制外部长音频支持状态。

不预设最新版依赖兼容当前声音环境。建立独立 `envs/alignment`，使用官方 Transformers 推理路径，先尝试无需编译的注意力实现，不将 vLLM 或 FlashAttention 设为必需。私有 Python 版本按实测锁定，不更改系统 Python。配音完成并退出后再运行对齐，避免两个模型同时占用显存。

版本、权重 revision、SHA-256、下载量、依赖约束和代码/模型许可在本机验证通过后固定，不能将 README 支持声明当成本项目兼容性结论。

## 流程

1. 输入解析：接受配音任务 ID，或音频 + UTF-8 稿件。任务模式读取当前选定音频、分段清单和实际配音文本。
2. 保存音频与文本摘要及原始来源；为引擎生成解码/重采样副本，不修改原文件。
3. 建立展示文本、实际朗读文本与对齐单元的映射。数字、单位、英文缩写无法可靠映射时标注异常，不能丢弃字符后宣称成功。
4. 本插件音频逐段对齐，再按真实样本偏移恢复全片时间。外部输入没有可靠边界时，按经验证的自动窗口策略处理。
5. 检查文本覆盖、时间单调性、范围、零时长、异常静音与疑似漏读。强制对齐不证明音频确实说出了每个词；需要独立的内容核对及明确的异常状态。
6. 依标点、语义边界、阅读长度与停留时间组合字幕。首版输出普通短行字幕，长度限制为可调整的保守规则，不宣称完成字体排版验证。
7. 导出 UTF-8 SRT、结构化时间戳和检查结果。可生成临时字幕预览用于抽查，视频正式渲染仍属于下一模块。

## 产物和恢复

每次任务独立目录，保存输入摘要、引擎版本、原始对齐结果、规范化映射、字幕条目、异常与导出文件。状态沿用 ready/needs_input/failed 等现有协议；可恢复有效分段。

主要产物：`subtitles.srt`、`alignment.json`、`checks.json`。时间统一以原始音频为基准，同时保留采样率与采样偏移，SRT 在导出时转换成毫秒。毫秒取整后再次验证字幕不越界、不重叠且结束晚于开始。显示原稿或配音稿必须有明确映射，不能用文字长度平均分配时间。

缓存键包含实际选定音频摘要、当前分段文本、展示文本、引擎/权重版本与字幕配置。配音重做或改稿后旧字幕失效；原稿文件本身不代表最新实际朗读内容。

## 插件接入（拟议接口，尚未实现）

`doctor --feature alignment`、`setup --feature alignment` 注册到共用 setup；不要新增字幕专用 setup skill。

CLI 拟为 `subtitles generate --job <speech-job-id>` 或 `subtitles generate --audio <file> --text-file <file>`，返回任务 ID 和产物。只允许本地文件；skill 根据最近任务选择明确的输入，遇到多个候选才询问。runtime 注册完成之前不把 alignment 写成可用能力。

## 实施顺序与验收

1. 最小引擎试验：先在独立环境对已验收的 72 秒配音做对齐，记录安装成本、耗时、内存/显存与时间戳覆盖。
2. 测试纯中文、数字日期金额、英文缩写、长停顿、故意漏读及局部重做。不以返回结果或无异常退出作为效果通过。
3. 候选达标后固定资源与依赖，接入通用 setup、本地 CLI、任务缓存、映射和 SRT 导出。
4. 最后创建字幕 skill 并验证安装包资源路径；原生 Agent 安装仍单独验收。

机器检查：无负数/越界/倒序/非法重叠；有效正文字符不静默缺失；失败区间明确提示；输入改变后不能复用旧结果；已有文件不覆盖。

人工检查：在 72 秒音频开头、中间、结尾及至少两个停顿位置抽查字幕，目标边界偏差不超过约 200 毫秒；此为验收目标，不是已测结论。英文与数字必须单独听看核对。全部通过后再进入一分钟视频合成。
