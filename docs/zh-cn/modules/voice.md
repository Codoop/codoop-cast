# 声音与配音模块

[English](../../en/modules/voice.md) | [简体中文](voice.md)

首版引擎为 GPT-SoVITS。已有 alpha 实现并在 Windows NVIDIA 开发机完成模型加载、参考配音及分段重做验证；使用方法和限制见[运行说明](../08-running-voice.md)，设计依据见[实施计划](../04-voice-implementation-plan.md)。

## 职责与输入输出

声音档案用户输入：本人或获授权的原始录音，名称可选。输出：可复用的声音档案。插件自动选段并本地转写；识别不可靠时才确认片段文字。短音频可选提供准确文字以跳过识别。模型和推理配置由插件管理，不要求用户选择。

配音用户输入：文本或稿件、声音档案。只有一个声音时自动使用；多个且未指定时再询问。输出：可试听及导出的 WAV。分段音频、生成清单和质量检查结果作为内部产物保存，支持后续字幕与视频流程。独立调用不要求存在调研报告。

## 实现路线

采用参考音频驱动的声音克隆。档案仅保存复用所需的参考条件。训练、微调及训练数据管理不属于产品范围，不设计相应 skill、命令、界面或后续任务。

引擎适配器提供内部就绪检查、参考档案验证和语音生成。仅暴露内容制作确实需要的操作，不将上游能力清单变成用户菜单。语速等调整可按自然语言意图映射到经过验证的内部参数。

## 工作流程

1. 验证原始录音可读取；本地转写后按语句/词时间戳选取模型可用片段，保留原录音和片段位置。不能自动识别人物身份，已知多人时需明确目标声音。
2. 规范数字、单位、缩写与多音字读法。
3. 按语义段落调用 TTS，保留相同声音条件和有效参数。
4. 检查文件、静音、异常时长；可用 ASR 辅助发现漏读和重复。
5. 提供试听和单段重试；自动重试次数有上限。
6. 统一音频格式、拼接段落与停顿，记录精确时长和偏移。

ASR 差异可能来自识别错误，只作为核查信号，不自动认定 TTS 正确或错误。跨段音色和语气连贯性仍需试听。

## 资源与恢复

模型与其他 GPU 阶段按资源限制排队，支持显式卸载。模型权重预下载后，推理阶段应能在断网条件下验证；不要假定依赖不会隐式联网。

记录引擎、模型权重版本、种子（若支持）、参数、输入摘要和参考档案版本。保存这些信息用于追踪，但不承诺不同硬件下逐样本完全一致。

验收：同一档案可多次调用；中文数字及混排样例可试听；单段失败不覆盖成功段；中间音频能独立交给对齐模块。
