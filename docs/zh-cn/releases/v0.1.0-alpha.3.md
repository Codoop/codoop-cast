# codoop-cast v0.1.0-alpha.3：统一技能显示名称

[English](../../en/releases/v0.1.0-alpha.3.md) | [简体中文](v0.1.0-alpha.3.md)

本次 Alpha 让技能列表中的 Codoop Cast 技能更容易与其他 Codoop 插件区分。

## 变化

- 全部 10 个技能的显示名称统一采用 `Codoop Cast: …` 前缀：Setup、Research、Script、Voice、Subtitles、Storyboard、Assets、Scenes、Video、Produce。
- 现有 `$codoop-*` 调用名、默认提示词和运行时行为保持不变。

## 升级

通过宿主更新完整插件，或在更新后的源码中重新运行备用安装器。

本次仅调整界面元数据，已有配置、声音和内容项目无需迁移。[Alpha 验证范围与限制](../29-release-readiness.md)仍然适用。

[版本对比](https://github.com/Codoop/codoop-cast/compare/v0.1.0-alpha.2...v0.1.0-alpha.3)。
