# codoop-cast v0.1.0-alpha.1

[English](../../en/releases/v0.1.0-alpha.1.md) | [简体中文](v0.1.0-alpha.1.md)

首个公开源码 Alpha，面向愿意反馈安装与内容质量问题的使用者。

- 10 个独立 Agent skills，支持话题调研、口播写作、GPT-SoVITS 参考声音配音、实际音频字幕对齐、分镜与 HTML 场景、MP4 导出。
- 项目版本管理、Agent 顺序批量制作、自动素材准备、局部重做及任务恢复。
- 英文 skill 指令，产物语言由共享/项目配置控制；按需安装私有环境，模型工具跨项目复用。
- 项目代码采用 Apache-2.0；模型、依赖、字体和素材保留各自许可。

当前验证范围为维护者 Windows + NVIDIA 中文制作流程及隔离备用安装。原生 Agent 安装、干净机器完整流程、AMD/macOS、英文配音听感和更多新话题批量质量仍待验证。不提供声音训练、数字人口型或自动投稿。

从 [安装与首次制作](../28-install-and-first-video.md) 开始。反馈时提供宿主/版本、系统/GPU、操作步骤和脱敏错误信息；不要公开参考录音、声音档案、凭据或完整私人任务目录。

这是一份发布说明草稿，创建文件不表示已经建立 GitHub Release 或上传远程。
