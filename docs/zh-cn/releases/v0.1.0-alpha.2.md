# codoop-cast v0.1.0-alpha.2：按配置制作视频

[English](../../en/releases/v0.1.0-alpha.2.md) | [简体中文](v0.1.0-alpha.2.md)

本次 Alpha 改进本地优先的话题到视频流程中的制作配置、skill 命名和项目文档。

## 主要变化

- **按配置制作视频**：从共享或项目配置读取语言、横竖屏、分辨率、帧率、字幕样式和头像位置，本次明确要求优先。视频配置逐字段继承，并固定到 output-profile.json，保持规划和渲染一致。
- **可预期的视觉修改**：实际格式变化需要新视觉计划；保留口播及来源内容，重做受影响画面和导出。实际 profile 不符合显式配置时，工作流 checkpoint 会拒绝通过。
- **统一 skill 名称**：10 个公开 skill 改用 codoop-*，例如 codoop-setup、codoop-research、codoop-voice、codoop-produce，与 codoop-flow 风格一致。
- **中英文项目文档**：docs/en/ 与 docs/zh-cn/ 提供语言切换；skill 指令和参考资料保持英文。

## 升级

通过宿主更新完整插件，或在更新后的源码中重新运行备用安装器。不要只复制单个 SKILL.md 而遗漏共享运行时。

备用安装器只移除属于本插件的旧发现链接，保留其他插件、声音、任务与内容项目。已有工作流会路由到新名称，不改写保存的历史计划。

仅含语言的旧配置仍可使用。新增视频默认要求时，直接告诉 Agent，例如“默认中文、竖屏 1080×1920、30 帧”。格式与覆盖规则见[制作配置](../31-production-configuration.md)。

## 验证

- 185 项运行时及制作契约测试通过。
- 10 个 skill 格式校验通过。
- 文档成对及 556 个本地链接检查通过。
- 已通过安装后的 CLI 保存横屏 1280×720 配置，并生成匹配宽高、帧率、字幕字号和头像显示状态的 profile；这次配置验证没有重新渲染视频或生成配音。

## Alpha 边界

媒体流程的实际验证范围仍为维护者 Windows + NVIDIA 中文环境。原生 Agent 安装、干净机器完整流程、Windows AMD、macOS、英文音质及更多新话题批量质量仍需分别验收。

生图依赖宿主已有工具；不包含声音训练、数字人口型或自动投稿。项目代码为 Apache-2.0，第三方模型、依赖、字体和素材保留各自条款。
