# 话题调研运行说明

[English](../en/19-research-running.md) | [简体中文](19-research-running.md)

> 状态说明：本文保留对应开发阶段的计划或验证记录。当前已实现能力与发布缺口以 [Alpha 发布状态](29-release-readiness.md) 为准；首次使用见 [安装指南](28-install-and-first-video.md)。

2026-10-17：新增 codoop-cast-research 独立 skill。可以只输入一个话题，也可以只提供本地资料，不依赖视频流程。用户以自然语言发起任务，Agent 读取资料、整理证据、撰写报告并调用本地导出工具。

## 能力与边界

- 联网时使用宿主已有的检索/浏览能力，优先原始资料；不绑定搜索厂商，不新增在线 API 服务或密钥。
- 离线时只读用户资料，说明时效范围；不会为了导出报告联网下载网页。首次初始化轻量 authoring 环境可能需要联网获取依赖，严格离线时应预先准备该环境。
- 不为调研安装 GPT-SoVITS、字幕模型或浏览器。报告验证与导出复用通用 setup 的 authoring 功能。
- 默认写给小白：先解释核心问题，再给必要知识点和例子；不要求凑固定章节或堆术语。中文问题默认中文报告。
- 未读取的网页、搜索摘要和无访问记录的链接不能作为已核实依据。资料不足时可交付 partial 报告，不能把命令成功冒充为事实完整可靠。

## 产物与交接

report.md 是易读报告；report.json 是规范化交接文件，包含稳定结论 ID、事实/推断/争议类型、证据片段、来源元数据、资料截至日期、冲突和未知项。checks.json 记录结构校验结果及边界。sources/ 保存相关证据摘记和摘要，不虚构网页全文归档。

report.schema.json 为独立报告规范，不加入现有八类视频制作包的必选清单。下游口播稿可将段落 claim_ids 关联到结论，并保留报告 artifact_id/revision。该口播稿 skill 尚未实现；本阶段不自动创建稿件或配音。

所有源文件相对报告目录定位；摘记保留 SHA-256。读取模式明确区分 full、excerpt、metadata 和 unavailable。excerpt 只表示读过相关部分，短摘记不能被描述为完整原文。访问时间和已知发布日期分开记录；不知道发布日期时为 null。

## 命令

通过 scripts/cast.ps1 或兼容 Python 运行 runtime/codoop-cast/cast.py：

```text
research validate --report-file <草稿目录/report.json>
research export --report-file <草稿目录/report.json> --output <新交付目录>
```

草稿由 Agent 根据实际研究结果生成。命令不搜索网页，不替代来源质量判断，也不能检测段落里所有未被结构化引用的断言。导出复制声明的证据摘记并生成易读报告，保留既有目录；修订用新版本和新输出目录。

默认普通调研以两轮检索、八个打开的候选来源作为可调整上限起点，已回答核心问题即可提前结束；不要求每篇必须八个来源。更深入任务依用户范围调整。重要问题覆盖不足时留下缺口，不无限检索。

## 验证

- 新增 11 项调研契约测试，验证可移植交付、结论身份保留、partial 状态、无证据拒绝、未读来源拒绝、来源摘记哈希、越界路径、无效引用、本地资料及已有输出保护。
- 现有 37 项普通测试与 23 项契约测试合计 60 项通过。
- 新 skill 通过 skill-creator 格式检查。
- 使用 MDN WebVTT 实际读取片段完成报告样例，严格区分源文档支持的事实与根据机制得出的推论；例子位于 examples/research-subtitle-timing。
- 在隔离中文及空格安装路径中，更新备用插件分发并通过安装后的 research export 命令；没有修改用户真实 Agent 安装目录。

上述验证证明本地校验与导出链可运行，不代表每个 Agent 的检索能力、报告事实正确率或所有原生插件安装已完成验证。后续优先实现口播稿 skill，然后处理稿件到配音的身份保留适配和完整编排。
